# MKT BGE Közösség – GitHub Pages demo

Anonimizált bemutatóverzió. A tagnevek és tagazonosítók demóértékekre cserélve; az elérhetőségi mezők helykitöltők. A tagokat ábrázoló kvízborítót személyeket nem tartalmazó illusztráció váltja fel.

## GitHub Pages

A projekt gyökérkönyvtárát töltsd fel egy GitHub-repositoryba, majd a **Settings → Pages** részen válaszd ki a `main` ágat és a gyökérmappát (`/(root)`). Az oldal az `index.html` fájlból indul.

## Fájlok

- `index.html`, `app.js`: felület és működés
- `styles.css`, `brand.css`: stílusok
- a gyökérben levő JS-, SVG- és PNG-fájlok: anonimizált demo-adatok és arculati elemek

Ez egy statikus, böngészőoldali demo. A módosítások helyi böngészőtárolóba kerülnek, nem szinkronizálódnak a tagok között, és nincs mögötte közös adatbázis vagy éles hitelesítés.
